#### Tic Tac Toe Game for The Odin Project

Tic Tac Toe in the web browser using CSS and Vanilla JavaScript.

The primary goal of this project was to practice a modular design pattern. We used closures to encapsulate variables and logic, expose simple interfaces, and keep clear separation of concerns.

The gameboard lives in its own module. It is acted on by the GameController module, and provides information to the DisplayController. The Players module sets player names based on the html text inputs in the Display UI and offers an interface for switching between active user or returning active user information.

I tried a few new (to me) CSS tricks for making this one responsive. Since it was such a simple layout, I had to give it a try!
